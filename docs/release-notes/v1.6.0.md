A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.0 – English and German

- The whole interface is now available in **English and German**: menus, filters, settings, messages, keyboard shortcuts, contact sheet and tile texture
- By default peek follows the Windows display language (German → German, otherwise English). Change it under **Settings → Appearance → Language**; the switch takes effect immediately
- Dates, numbers and sizes follow the chosen language (e.g. `17 Aug 2024`, `1,234`, `1.5 MB`)
- Search parameters work in both languages, whatever the interface language: `width:`, `height:`, `size:`, `date:`, `captured:`, `duration:`, `extension:`, `camera:` as well as `Breite:`, `Höhe:`, `Größe:`, `Datum:`, `Aufgenommen:`, `Dauer:`, `Endung:`, `Kamera:`. Saved searches keep working
- File type names (e.g. “JPEG image”) come from Windows and therefore follow the Windows language

## Known limitations

- Not signed, hence the SmartScreen notice on first start
- Images in the viewer are shown up to 8192 px on the long edge
- Not yet included: command palette, animated GIFs, color management
