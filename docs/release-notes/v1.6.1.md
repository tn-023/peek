A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.1

- **Open with peek:** opening an image with peek (e.g. **Open with** in Explorer) now shows it directly in the image viewer. **Esc** or the close button leads to the folder in peek, with the image selected
- **Details view:** the name column fills the window; date, type, size and resolution stay at the right edge. Change their width at their left edge
- **Details view:** dragging on a row next to the icon and name starts a selection rectangle (dragging the name still drags the files)
- **Network drives:** mapped network drives (with a drive letter) now appear under Drives and can be browsed and used as collections. peek contains no network code of its own – Windows reads the files. For speed on the network, peek first shows the small preview embedded in photos and reads whole files only afterwards; collections on network drives are indexed by name, size and date only
- **Online-only files** (Google Drive, OneDrive): images that are only stored in the cloud can now be opened in the viewer – the sync app downloads that one file. They still get no thumbnail, so browsing a folder downloads nothing
- In Explorer (e.g. **Open with**), peek is now listed simply as “peek”. Windows may keep showing the old name for a while, as it caches app names

## Deutsch

**Neu in v1.6.1**
- **Öffnen mit peek:** Ein Bild, das mit peek geöffnet wird (z. B. über **Öffnen mit** im Explorer), erscheint jetzt direkt im Bildbetrachter. **Esc** oder die Schließen-Schaltfläche führen zum Ordner in peek, das Bild ist markiert
- **Detailansicht:** Die Namensspalte füllt das Fenster, Datum, Typ, Größe und Auflösung bleiben am rechten Rand. Ihre Breite ändert man an ihrer linken Kante
- **Detailansicht:** Ziehen auf einer Zeile neben Symbol und Name beginnt ein Auswahlrechteck (Ziehen am Namen zieht weiterhin die Dateien)
- **Netzlaufwerke:** Eingebundene Netzlaufwerke (mit Laufwerksbuchstaben) erscheinen jetzt unter Laufwerke und lassen sich durchsuchen und als Sammlung anlegen. peek enthält keinen eigenen Netzwerkcode – die Dateien liest Windows. Damit es über das Netz schnell geht, zeigt peek zuerst die in Fotos eingebettete kleine Vorschau und liest ganze Dateien erst danach; Sammlungen auf Netzlaufwerken erfasst der Index nur nach Name, Größe und Datum
- **Nur online verfügbare Dateien** (Google Drive, OneDrive): Bilder, die nur in der Cloud liegen, lassen sich jetzt im Betrachter öffnen – die Sync-App lädt dabei genau diese Datei herunter. Vorschaubilder gibt es für sie weiterhin nicht, beim Durchblättern eines Ordners wird also nichts heruntergeladen
- Im Explorer (z. B. bei **Öffnen mit**) heißt peek jetzt nur noch „peek“. Windows zeigt den alten Namen eventuell noch eine Weile an, weil es App-Namen zwischenspeichert
