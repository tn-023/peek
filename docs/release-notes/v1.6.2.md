A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.2

- **Image viewer in full screen** (Settings → Appearance): on by default. Switched off, the viewer and image comparison fill the screen without a frame, but the Windows taskbar stays visible
- **More photo details** in the info panel: lens, aperture, exposure and ISO, if the image contains them
- **New folder:** in the context menu of the empty space and with **Ctrl+Shift+N**; the new folder is selected and ready to be renamed
