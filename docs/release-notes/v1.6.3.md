A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.3

- **Groups in the image cloud:** with grouping switched on (sort menu), the cloud is split into up to 6 vertical strips side by side, with title and count at the top like in the other views. Too many groups are merged with their neighbors (e.g. "A–C", "2019 – 2021"), too few are split further by date, size or resolution; names are split only by their first character
- Clicking a strip title moves the camera onto that strip, **Home** shows everything again
