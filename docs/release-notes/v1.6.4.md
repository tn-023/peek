A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.4

- **Smoother animations:** peek now draws in step with the display (also at 120, 144 or 165 Hz); scrolling, the image cloud and sliding panels move more evenly
- **Less load:** the image viewer no longer re-filters the photo on every mouse movement; thumbnails are uploaded in small portions while scrolling
- **Image cloud with many files without preview:** cards with icon and file name are drawn much faster; the icon glides instead of jumping when a name changes between one and two lines
- **Settings:** the scroll bar can be dragged and clicked with the mouse
- **List view:** the mouse wheel scrolls two and a half rows per notch; a selection can be dragged anywhere on a selected row, not only on the file name

## Deutsch

**Neu in v1.6.4**
- **Flüssigere Animationen:** peek zeichnet jetzt im Takt des Bildschirms (auch bei 120, 144 oder 165 Hz); Scrollen, Bilderwolke und einfahrende Leisten bewegen sich gleichmäßiger
- **Weniger Last:** Der Bildbetrachter filtert das Foto nicht mehr bei jeder Mausbewegung neu; Vorschaubilder werden beim Scrollen in kleinen Portionen geladen
- **Bilderwolke mit vielen Dateien ohne Vorschau:** Karten mit Symbol und Dateiname werden deutlich schneller gezeichnet; das Symbol gleitet, statt zu springen, wenn ein Name zwischen einer und zwei Zeilen wechselt
- **Einstellungen:** Die Bildlaufleiste lässt sich mit der Maus ziehen und anklicken
- **Detailansicht:** Das Mausrad scrollt zweieinhalb Zeilen je Raste; eine Auswahl lässt sich überall auf einer ausgewählten Zeile ziehen, nicht nur am Dateinamen
