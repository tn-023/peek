A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.5

- **HEIC/HEIF:** photos from iPhones and many Android phones (`.heic`, `.heif`, `.hif`) are shown like other images – thumbnails, viewer, image cloud, compare, filters. The image data is decoded by the Windows codec (Microsoft's free "HEIF Image Extensions" and the "HEVC Video Extensions" from the Store). Size, rotation, capture date, camera, lens, aperture, exposure and ISO are read by peek itself, so sorting by capture date works even without the codec; without it the info panel says which extensions are needed. Cropping saves a PNG copy
- **Image cloud – keyboard:** arrow keys move the camera; with an image selected, ← / → step to the previous / next image
- **Image cloud – spacing:** Ctrl+mouse wheel changes the spacing of all cards, Ctrl+0 restores the default; switching to the cloud always starts with the default spacing
- **Image cloud – large folders:** much smoother with tens of thousands of files: only moving cards are animated, only cards in view are processed, thumbnails are taken over in portions
- **Image cloud – file names** appear only on near cards and fade in; their line breaks are computed far less often
- **Keyboard shortcuts:** new section "Image cloud"

## Deutsch

**Neu in v1.6.5**
- **HEIC/HEIF:** Fotos von iPhones und vielen Android-Handys (`.heic`, `.heif`, `.hif`) erscheinen wie andere Bilder – Vorschaubilder, Betrachter, Bilderwolke, Vergleich, Filter. Die Bilddaten dekodiert der Codec von Windows (die kostenlosen „HEIF-Bilderweiterungen“ und die „HEVC-Videoerweiterungen“ von Microsoft aus dem Store). Größe, Drehung, Aufnahmedatum, Kamera, Objektiv, Blende, Belichtung und ISO liest peek selbst, die Sortierung nach Aufnahmedatum funktioniert also auch ohne Codec; fehlt er, nennt der Info-Bereich die nötigen Erweiterungen. Zuschneiden speichert eine PNG-Kopie
- **Bilderwolke – Tastatur:** Pfeiltasten bewegen die Kamera; mit ausgewähltem Bild springen ← / → zum vorigen / nächsten Bild
- **Bilderwolke – Abstand:** Strg+Mausrad ändert den Abstand aller Karten, Strg+0 stellt den Standard wieder her; beim Wechsel zur Wolke gilt immer der Standardabstand
- **Bilderwolke – große Ordner:** deutlich flüssiger bei zehntausenden Dateien: nur bewegte Karten werden animiert, nur sichtbare bearbeitet, Vorschaubilder portionsweise übernommen
- **Bilderwolke – Dateinamen** erscheinen erst auf nahen Karten und werden eingeblendet; ihre Zeilenumbrüche werden viel seltener berechnet
- **Tastenkombinationen:** neuer Abschnitt „Bilderwolke“
