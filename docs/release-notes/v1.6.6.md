A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.6

- **Filter bar:** filters that no longer fit into a narrow window move into a "…" menu left of "Sort", each with its options as a submenu; the button is tinted when one of the hidden filters is active
- **Drag & drop:** dropping files never opens anything in peek any more. Files dropped onto the empty space of the view are copied or moved into the folder shown – from Explorer, other apps and between peek windows (same drive: move, otherwise copy; `Ctrl` = copy, `Shift` = move). Opening with peek works via "Open with" in Explorer
- **Fixed:** dropping onto a folder tile or a folder in the sidebar was not recognized and opened the file instead of copying it
- **Opened from Explorer:** the viewer starts with the top bar visible; a large back arrow in the top left corner leads to the folder view, the X closes peek. Closing this way keeps the folder peek opens on its next normal start
- **Animations:** drop-down menus, path lists, the date picker and submenus (e.g. "Open with") slide in and out very quickly; the bar at the top of the viewer and the search history slide as well
- **Fixed:** a thin line on the info panel below the hidden viewer bar

## Deutsch

**Neu in v1.6.6**
- **Filterleiste:** Filter, die bei schmalem Fenster nicht mehr passen, landen in einem Menü „…“ links neben „Sortieren“, jeweils mit ihren Optionen als Untermenü; der Knopf ist getönt, wenn einer der verborgenen Filter aktiv ist
- **Ziehen und Ablegen:** Ablegen öffnet in peek nichts mehr. Auf der freien Fläche abgelegte Dateien werden in den angezeigten Ordner kopiert oder verschoben – aus dem Explorer, anderen Apps und zwischen peek-Fenstern (gleiches Laufwerk: verschieben, sonst kopieren; `Strg` = kopieren, `Umschalt` = verschieben). Öffnen mit peek geht über „Öffnen mit“ im Explorer
- **Behoben:** Ablegen auf eine Ordner-Kachel oder einen Ordner in der Seitenleiste wurde nicht erkannt und öffnete die Datei, statt sie zu kopieren
- **Aus dem Explorer geöffnet:** Der Betrachter startet mit sichtbarer Leiste; ein großer Zurück-Pfeil oben links führt in die Ordneransicht, das X beendet peek. Wird peek so beendet, bleibt der Ordner für den nächsten normalen Start unverändert
- **Animationen:** Aufklappende Menüs, Pfadlisten, die Datumsauswahl und Untermenüs (z. B. „Öffnen mit“) schieben sich sehr schnell herein und hinaus; auch die Leiste im Betrachter und die Suchliste gleiten
- **Behoben:** eine dünne Linie auf dem Info-Bereich unter der ausgeblendeten Betrachterleiste
