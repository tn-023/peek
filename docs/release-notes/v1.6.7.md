A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.7

- **Open with a single click:** new option in Settings → Appearance, "Open folders and files": double-click (default) or single click, like the corresponding Explorer option. A click without Ctrl/Shift opens the item; selecting works with Ctrl/Shift, the selection rectangle or a right-click
- **Sort order per folder:** sort key, direction and grouping are remembered for each folder (also for collections and bookmarks); folders without a stored choice open sorted by name, ascending
- **Fixed:** closing the viewer opened from Explorer with the X also closed the window behind it. The X and the back arrow now act when the mouse button is released
