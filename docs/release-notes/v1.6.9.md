A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.6.9

- **Find duplicates:** new entry at the bottom of the search field dropdown. peek searches the images of the current view (folder, with subfolders, collection, search result, with filters) for visually identical copies: also smaller, re-saved or converted ones, and copies with other metadata, names or locations. Series shots, edited, cropped, mirrored or rotated versions do not count. The result is its own list with thumbnail, name, size, date, resolution, type and full location; the better values of each group are bold. The best copy (highest resolution, then larger, then older file) stays unchecked, all others are pre-selected. "Delete x duplicates" moves them to the recycle bin; at least one image of each group always stays. A click on a thumbnail opens the comparison with the best copy on the left, `←`/`→` step through the group. Thumbnails can be zoomed with the slider at the bottom right, `Ctrl`+mouse wheel or `Ctrl` `+`/`−`
- **Saved searches:** while a search or filter is active, "Save search" appears next to the sort button. The search is stored with its place, search text, filters and sort order and appears with an automatic name below the collections in the sidebar. Right-click to rename it in place or delete it; while it is shown, the button reads "Delete search"
- **Remove metadata:** for a single JPEG, PNG or WebP image the info panel offers "Remove metadata". Choose Save (replaces the file) or Save as …. The image data is not re-encoded; EXIF (including location and camera), XMP, IPTC, comments and text blocks are removed, colour profile, transparency and animation stay. JPEG keeps its rotation so the image is not shown sideways
- **Image cloud:** opening or closing a side panel or resizing the window no longer shifts the cloud once you have moved, zoomed or selected something

## Deutsch

**Neu in v1.6.9**
- **Duplikate suchen:** neuer Eintrag ganz unten im Dropdown des Suchfelds. peek durchsucht die Bilder der aktuellen Ansicht (Ordner, mit Unterordnern, Sammlung, Suchergebnis, mit Filtern) nach visuell identischen Kopien: auch verkleinerte, neu gespeicherte oder umgewandelte und solche mit anderen Metadaten, Namen oder Orten. Serienbilder, bearbeitete, beschnittene, gespiegelte oder gedrehte Fassungen zählen nicht. Das Ergebnis ist eine eigene Liste mit Vorschaubild, Name, Größe, Datum, Auflösung, Typ und vollem Speicherort; die besseren Werte jeder Gruppe sind fett. Die beste Fassung (höchste Auflösung, dann größere, dann ältere Datei) bleibt abgewählt, alle anderen sind vorausgewählt. „x Duplikate löschen“ legt sie in den Papierkorb; mindestens ein Bild jeder Gruppe bleibt immer. Ein Klick auf ein Vorschaubild öffnet den Vergleich mit der besten Fassung links, `←`/`→` blättern durch die Gruppe. Die Vorschaubilder lassen sich mit dem Regler unten rechts, `Strg`+Mausrad oder `Strg` `+`/`−` vergrößern
- **Gespeicherte Suchen:** Bei aktiver Suche oder aktivem Filter erscheint neben dem Sortieren-Knopf „Suche speichern“. Die Suche wird mit Ort, Suchtext, Filtern und Sortierung gespeichert und steht mit automatischem Namen unter den Sammlungen in der Seitenleiste. Rechtsklick: direkt umbenennen oder löschen; wird sie angezeigt, steht dort „Suche löschen“
- **Metadaten entfernen:** Für ein einzelnes JPEG-, PNG- oder WebP-Bild bietet der Info-Bereich „Metadaten entfernen“. Zur Wahl stehen Speichern (ersetzt die Datei) und Speichern unter …. Die Bilddaten werden nicht neu kodiert; EXIF (auch Aufnahmeort und Kamera), XMP, IPTC, Kommentare und Textblöcke werden entfernt, Farbprofil, Transparenz und Animation bleiben. JPEG behält die Drehung, damit das Bild nicht quer liegt
- **Bilderwolke:** Öffnen oder Schließen einer Seitenleiste oder eine neue Fenstergröße verschieben die Wolke nicht mehr, sobald sie bewegt, gezoomt oder ein Bild ausgewählt wurde
