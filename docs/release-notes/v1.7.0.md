A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.7.0

- **Animations (new setting, off by default):** under Appearance, "Animations" switches on a few quick, unobtrusive movements. Tiles slide in one after another from the left and list rows from below whenever a folder, collection, bookmarks or saved search is opened, the view switches between tiles and list, or the search or filters change. Hover effects fade out quickly when the mouse leaves an element, also in the image cloud and the timeline. Opening an image from the tiles, the list, the image cloud or the timeline lets it grow from its thumbnail into the viewer while the view behind fades to black; closing reverses the movement. With the setting off, everything stays as before
- **Timeline:** scrolls further at the start and the end, so the first and last images can stand in the middle, where they are largest; it starts that way the first time a folder is opened. The overview at the bottom now shows exactly the visible part. Works with the mouse wheel, keys, the overview and the middle mouse button
- **Slideshow:** starting it from the folder view no longer shows the first image for a moment before it fades in

## Deutsch

**Neu in v1.7.0**
- **Animationen (neue Einstellung, standardmäßig aus):** Unter „Darstellung“ schaltet „Animationen“ ein paar schnelle, unaufdringliche Bewegungen ein. Kacheln gleiten nacheinander von links herein, Listenzeilen von unten – beim Öffnen eines Ordners, einer Sammlung, der Merkliste oder einer gespeicherten Suche, beim Wechsel zwischen Kacheln und Liste und wenn sich Suche oder Filter ändern. Hover-Effekte blenden schnell aus, wenn die Maus ein Element verlässt, auch in der Bilderwolke und der Zeitleiste. Ein Bild aus Kacheln, Liste, Bilderwolke oder Zeitleiste wächst beim Öffnen aus seinem Vorschaubild in den Betrachter, während die Ansicht dahinter nach Schwarz abblendet; beim Schließen läuft es umgekehrt. Ist die Einstellung aus, bleibt alles wie bisher
- **Zeitleiste:** lässt sich am Anfang und Ende weiter scrollen, bis das erste bzw. letzte Bild in der Mitte steht, wo es am größten ist; so startet sie auch beim ersten Öffnen eines Ordners. Die Übersicht unten zeigt jetzt genau den sichtbaren Ausschnitt. Gilt für Mausrad, Tasten, die Übersicht und die mittlere Maustaste
- **Diashow:** Beim Start aus der Ordneransicht blitzt das erste Bild nicht mehr kurz auf, bevor es einblendet
