A fast, portable media viewer for Windows 11 (x64) – no installation, no admin rights, no network features.

*Deutsch: siehe unten.*

## Download and start

1. Download `peek.exe` (or the ZIP file) and put it in any folder, e.g. on a USB stick.
2. Start it. The file is not signed, so Windows SmartScreen shows a notice on first start: **More info → Run anyway**.
3. Portable mode: put an empty file `peek.portable` next to `peek.exe` – index and settings (encrypted) then stay in the folder `peek-data` next to it.

## New in v1.8.0

- **Accent color:** Settings > Appearance > "Accent color" offers the Windows accent color (default, as before), the 48 colors of the Windows settings, recently used colors and "Custom color …" with a color field, brightness slider, hex value and RGB or HSV values. peek recolors while you pick; Cancel restores the previous color. Text on the accent color switches between white and black for best contrast
- **Smooth viewer animation:** on Windows 11 the window no longer uses a system title bar of its own. peek draws a title bar that looks and works like the Windows one (icon, title, the original minimize, maximize and close buttons with snap layouts, dragging, double-click, window menu). Because the window frame no longer changes, opening and closing the image viewer no longer makes the window behind it jump, also when maximized
- **Deleting keeps your place:** after deleting, the neighbouring item is selected and stays in view instead of jumping to the start
- **Path bar:** clicking a parent folder selects the folder you came from and keeps it in view, like going back or up

## Deutsch

**Neu in v1.8.0**
- **Akzentfarbe:** Einstellungen > Darstellung > „Akzentfarbe“ bietet die Windows-Akzentfarbe (Standard, wie bisher), die 48 Farben der Windows-Einstellungen, zuletzt verwendete Farben und „Eigene Farbe …“ mit Farbfeld, Helligkeitsregler, Hex-Wert und RGB- bzw. HSV-Werten. peek färbt sich schon beim Auswählen um; „Abbrechen“ stellt die vorige Farbe wieder her. Text auf der Akzentfarbe wird je nach Kontrast weiß oder schwarz
- **Flüssige Animation zum Bildbetrachter:** Unter Windows 11 hat das Fenster keine eigene Titelleiste von Windows mehr. peek zeichnet eine Titelleiste, die aussieht und funktioniert wie die von Windows (Symbol, Titel, die originalen Knöpfe Minimieren, Maximieren und Schließen mit Andock-Layouts, Verschieben, Doppelklick, Fenstermenü). Weil sich der Fensterrahmen nicht mehr ändert, springt das Fenster beim Öffnen und Schließen des Bildbetrachters nicht mehr, auch maximiert nicht
- **Löschen behält die Stelle:** Nach dem Löschen ist das benachbarte Element ausgewählt und bleibt sichtbar, statt an den Anfang zu springen
- **Pfadleiste:** Ein Klick auf einen übergeordneten Ordner wählt dort den Ordner aus, aus dem man kommt, und hält ihn sichtbar – wie bei Zurück und „Nach oben“
